# Auth page avatar images

Place up to 3 avatar images here for the "Trusted by" section on the login/signup page.

**Supported files:**
- `avatar-1.jpg` (or .png, .webp) — first circle
- `avatar-2.jpg` — second circle  
- `avatar-3.jpg` — third circle

Use square or portrait images; they will be displayed as 32×32px circles. If a file is missing, a placeholder circle is shown.
